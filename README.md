## 🚀 Проекты

### 🛠️ [ZapretRoblox](https://github.com/VearyTry/ZapretRoblox)
Скрипт для автоматической настройки обхода DPI, созданный для комфортной игры в Roblox.
- **Особенности:** Не требует использования VPN или установки дополнительного программного обеспечения. Настройка происходит автоматически в STARTME.bat файле.

### 🌹 [AskaVPN](https://vpn.aska.lol)
Являюсь частью команды разработчиков бесплатного VPN-сервиса **AskaVPN**.
- **Особенности проекта:** Полностью бесплатная подписка, широкий выбор серверов и стран, функция автоматического выбора оптимального сервера. 
- **Что имеем:** Собственные сервера, парсеры, веб-сайты, боты, ИИ, дружелюбное развивающееся сообщество, свои каналы, админы, своя команда и многое другое.

### 🌄 [ЯлтаВПН](https://yaltavpn.netlify.app)
Являюсь частью команды **ЯлтаВПН**!
- **Особенности:** ПОЛНОСТЬЮ бесплатный проект, с большим списком серверов и стран.
- **Инфраструктура:** Мы имеем собственный парсер серверов, а также проверка конфигов автоматически! Это значит, что конфиги будут автоматически проверяется перед тем, как попасть в подписку.

### 🌊 [WSVPN](https://wsvpn.netlify.app)
Выступаю в роли контрибутора открытого проекта **WSVPN**!
- **Особенности:** Ставка на ручную модерацию. Каждая конфигурация проверяется администратором лично перед публикацией. Такой подход позволяет отсеивать нестабильные узлы, благодаря чему предоставленные конфиги сохраняют работоспособность месяцами.
- **Экосистема проекта:** Настоящая платформа для сообщества, включающая собственный сайт, GitHub-репозиторий с открытым кодом, Telegram-канал, бота и полноценный форум для обсуждения и технической поддержки.
